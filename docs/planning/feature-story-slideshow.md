# Feature Request: Story Slideshow Mode

**Status:** Future (V3+)
**Priority:** Low
**Effort:** Small

---

## Description

Add auto-advancing slideshow mode for presenting memories as a continuous story.

## User Story

As a user, I want to sit back and watch my memories play automatically like a slideshow so that I can share them with others or enjoy them hands-free.

## Requirements

### Core Features
- Auto-advancing slideshow of entries
- Fullscreen mode
- Timing control (e.g., 3s, 5s, 10s per page)
- Play/pause controls
- Exit slideshow button

### Optional Features
- Optional transitions (fade, slide)
- Selectable subsets (e.g., specific year or tag group)
- Background music support
- Share slideshow link

## Technical Notes

- Reuse existing flipbook rendering
- Add timer-based page advancement
- Consider performance in fullscreen mode

## Dependencies

- V1 complete (flipbook viewer)

## Success Criteria

- Slideshow advances automatically at set interval
- Smooth transitions between pages
- Easy to start/stop/exit
- Works in fullscreen mode
