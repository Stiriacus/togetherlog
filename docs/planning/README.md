This directory contains **feature requests only** - planned work for future releases.

## Guidelines

### What Belongs Here
- **Feature requests** - Descriptions of planned features with user stories, requirements, and acceptance criteria
- **Next-to-do items** - Features committed for upcoming releases
- Files should focus on **WHAT** to build, not detailed implementation plans

### What Doesn't Belong Here
- **Technical specifications** - Moved to `/docs/` (e.g., `a5-layout-coordinate-specification.md`)
- **Completed work** - Moved to `/docs/archive/`
- **Roadmaps and meta docs** - See `/docs/archive/` for historical roadmaps

## Workflow

1. **Create feature request** - Write feature-*.md with clear requirements
2. **Prioritize** - Organize into release phases (V1.5, V2, V3+)
3. **Implement** - Build the feature
4. **Archive** - Move completed planning docs to `/docs/archive/`
5. **Document** - Update `/docs/CHANGES.md` with what was shipped
